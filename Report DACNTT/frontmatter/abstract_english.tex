{\fontsize{15pt}{18pt}\selectfont \textbf{BUILDING A HYBRID RECOMMENDATION MODEL COMBINING MATRIX FACTORIZATION AND DEEP NEURAL NETWORKS}\par}
\vspace{0.5cm}
{\fontsize{16pt}{19.2pt}\selectfont \textbf{ABSTRACT}\par}
\end{center}
\vspace{0.2cm}

Recommending fashion products from real transaction data faces two difficulties. The interaction matrix between customers and items is very sparse, while matrix factorization (MF) learns only from customer and item identifiers through a linear inner product. This project builds NeuMF-F, a hybrid model that keeps the two-branch structure of Neural Matrix Factorization (NeuMF): a generalized matrix factorization (GMF) branch and a multi-layer perceptron (MLP) branch. Every customer and item is represented by an identifier embedding plus a projection of features, namely item attributes and text descriptions, customer information, recent sales and the customer's purchase rhythm.

The model is evaluated on the H\&M fashion transaction dataset. Data are split by time, features use only information available before the prediction time, and configurations are selected on a separate customer sample. Final results are measured on an independent customer sample under a pre-registered plan with statistical testing. NeuMF-F is compared with baselines from three groups, all tuned with the same budget.

NeuMF-F significantly outperforms the fully tuned baselines, and this result holds again on the Amazon Beauty dataset. The main conclusion is that adding features clearly improves recommendation quality over using identifiers alone, with temporal features contributing the most. The feature-augmented models lead on both datasets under both early and late fusion. The project also builds a demo system that illustrates the recommendations for each customer.
