{\fontsize{15pt}{18pt}\selectfont \textbf{BUILDING A HYBRID RECOMMENDATION MODEL COMBINING MATRIX FACTORIZATION AND DEEP NEURAL NETWORKS}\par}
\vspace{0.5cm}
{\fontsize{16pt}{19.2pt}\selectfont \textbf{ABSTRACT}\par}
\end{center}
\vspace{0.2cm}

Recommending fashion products from real transaction data faces two difficulties. The interaction matrix between customers and items is very sparse, and matrix factorization (MF) models the user-item match only linearly through an inner product. This project builds NeuMF-F, a hybrid model that keeps the two-branch structure of Neural Matrix Factorization (NeuMF): a generalized matrix factorization (GMF) branch and a multi-layer perceptron (MLP) branch. Every customer and item is represented by an identifier embedding plus a projection of features, namely item attributes and text descriptions, customer information, recent sales and the customer's purchase rhythm.

The model is evaluated on the H\&M fashion transaction dataset. Data are split by time, features use only information available before the prediction time, and configurations are selected on a separate customer sample. Conclusions are drawn once on an independent customer sample under a pre-registered plan with statistical testing. NeuMF-F is compared with baselines from three groups, all tuned with the same budget.

The main conclusion is that adding features clearly improves recommendation quality over using identifiers alone, and this conclusion holds again on the Amazon Beauty dataset. In contrast, the early fusion of the two branches in NeuMF-F gives no clear advantage over late fusion. The project also builds a demo system that illustrates the recommendations for each customer.
